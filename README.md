## Проблемы в исходном коде:
- Длинная функция process_checkout (70+ строк)
- Магические числа (0.21, 0.10, 200, 100 и др.)
- Нарушение принципа единственной ответственности
- Сложная логика скидок
- Дублирование проверок

## Выполненные улучшения:

### 1. Вынесены константы
Все числовые значения заменены на именованные константы:
- `TAX_RATE = 0.21`
- `DEFAULT_CURRENCY = "USD"`
- `MIN_AMOUNT_FOR_SAVE20 = 200`
- И другие

### 2. Разделена большая функция
Созданы отдельные функции:
- `validate_order_data()` - валидация
- `calculate_subtotal()` - подсчёт суммы
- `calculate_discount()` - скидки
- `calculate_tax()` - налоги
- `generate_order_id()` - ID заказа

### 3. Упрощена основная логика
`process_checkout()` теперь читается как сценарий:
1. Разбор запроса
2. Валидация
3. Подсчёты
4. Возврат результата
